# Engineering notes (historical)

file is a plan, audit, or checklist written before or during a specific
piece of work — kept so the reasoning behind past changes stays
discoverable. They are **not** maintained after the fact and may
describe behavior that has since changed.

For current, maintained docs see the parent [`docs/`](../) directory and
the project [README](../../README.md).
